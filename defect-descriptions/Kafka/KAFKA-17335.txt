Lack of default for URL encoding configuration for OAuth causes NPE
KAFKA-16345 added a new client configuration option SASL_OAUTHBEARER_HEADER_URLENCODE. This is an optional configuration, so the user does not need to provide it. When an AdminConfig, ConsumerConfig, or ProducerConfig object is created, it uses the default value of DEFAULT_SASL_OAUTHBEARER_HEADER_URLENCODE if the value is not present.
However, if the configuration is created as a plain Map or Properties and the sasl.oauthbearer.header.urlencode key is not present, it can lead to a NullPointerException. This occurs because the code in AccessTokenRetriever.create() assumes that there is always a value present in the incoming configs parameter. But if there is not an entry for the sasl.oauthbearer.header.urlencode key in the map, a NullPointerException is thrown.
